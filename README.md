# meu-cv

Currículo em formato web, construído com HTML e CSS, pronto para ser publicado no GitHub Pages.

## Conteúdo do projeto

- `index.html`: estrutura do currículo
- `index.css`: estilos e layout responsivo

## O que falta personalizar

Substitua todos os dados de exemplo por suas informações reais:

- nome completo
- telefone e email
- cidade/estado
- links de LinkedIn, GitHub, portfólio e blog
- formação acadêmica
- projetos, experiências, cursos e certificações
- idiomas, atividades extracurriculares, publicações e interesses

## Como publicar no GitHub

1. Crie um repositório novo chamado `meu-cv` no GitHub.
2. Envie estes arquivos para esse repositório.
3. No repositório, abra `Settings` > `Pages`.
4. Em `Build and deployment`, selecione `Deploy from a branch`.
5. Escolha a branch principal (`main` ou `master`) e a pasta `/ (root)`.
6. Salve as configurações e aguarde a publicação.

## Links que você deve entregar

Depois da publicação, envie:

- link do repositório GitHub
- link do site no GitHub Pages

## Estrutura sugerida de entrega

- Repositório: `https://github.com/seuusuario/meu-cv`
- Site: `https://seuusuario.github.io/meu-cv/`
